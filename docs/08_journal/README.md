# 개발 일지 (Dev Journal)

매 작업마다 **무엇을 / 어떤 파일을 / 어떻게 / 왜 / 무슨 기능**으로 만들었는지 일기처럼 한 파일로 기록한다.
목적: 시간이 지나도, 그리고 **남에게 설명할 때도** 코드의 의도와 동작을 바로 떠올릴 수 있게.

## 파일 규칙
- 파일명: `<역할>-<번호>-<영문슬러그>.md` 예) `A-02-import-movies.md`
  - 역할: 개발자 A = `A`, 개발자 B = `B` (협업 작업은 작성자 기준)
  - 번호: 그 역할의 작업 순서(2자리, `01`부터)
  - 제목은 파일명은 영문 슬러그, 문서 안 H1 제목은 한글 OK
- 새 작업 = 새 파일. 시간순으로 번호를 올린다.
