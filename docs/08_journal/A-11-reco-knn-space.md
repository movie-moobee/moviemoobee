# A-11 · 추천 kNN 공간: 2D 좌표 vs 고차원 — 분리 검토 (계획) — 4.3 / 4.4

- 날짜 / 일정ID / 담당: 2026-06-22 · 4.3·4.4 때 재검토 · 김호준
- 상태: **검토/보류 (미구현)** — 지도 UX 작업 중 발견. 4.3(추천 페이지)·4.4(지도 탐색) 때 적용 여부 결정.
- 한 줄 요약: 안전 추천 kNN이 **2D UMAP 좌표**에서 돌기 때문에, UMAP 투영 아티팩트가 추천에 새어들 *이론적* 가능성이 있다. 실측은 국소 밀도가 막아주지만 0은 아님. 완전 차단하려면 **추천 kNN을 고차원 특징공간(코사인)에서, 2D 지도는 표시 전용**으로 분리하면 된다. **지금은 보류** — 데모상 누수 0이라 시급하지 않음.

## 배경 / 문제
- 현재 안전 추천(F-REC, areas.py)은 **2D UMAP 좌표(umap_x, umap_y)의 유클리드 kNN**으로 후보를 뽑는다(A-08).
- 그런데 UMAP 2D는 **국소 이웃만 보존하고 전역 배치는 근사**다. 멀리 떨어진 무리의 절대 거리·"사이" 위치는 투영 아티팩트(의미 없음).
- 질문(김호준): 로맨스만 본 사용자에게, 2D에서 우연히 가까워 보이는 **겟아웃·메멘토 같은 무관 장르**가 안전 추천으로 튀어나올 수 있지 않나?

## 진단 (데이터)
- **고차원에선 무관이 정확히 잡힌다**: 노트북(드라마/로맨스) ↔ 겟아웃·메멘토(스릴러) 코사인 유사도 = **0.000(완전 직교)**, 모든 가중치 설정에서 동일. → "노트북이 둘 사이"는 순수 2D 투영 아티팩트(가중치 재빌드로 안 고쳐짐).
- **그런데 2D 추천 실측은 누수 없음**: 로맨스만 본 데모(genre_romance, 로맨스 12편) 안전추천 Top10 = **10편 전부 [로맨스] 포함**(컨트롤러·퍼펙트센스·그녀류 SF로맨스 등, 거리 d≈0.01). 호러/순수스릴러 0건.

## 왜 지금은 대체로 안전한가 — 국소 밀도가 방패
- kNN은 **가장 가까운(nearest)** 이웃을 뽑는다. 로맨스 군집엔 진짜 로맨스 영화가 **거리 0.01에 수두룩** → Top N을 다 채움.
- 겟아웃은 노트북에서 **거리 7.5** → 순번이 한참 뒤라 안 올라옴.
- 즉 아티팩트는 **전역 거리**를 망치지만 kNN은 **국소**만 보고, UMAP은 국소를 잘 보존한다. 카탈로그가 조밀(5000편)할수록 자동 방어.

## 엣지 케이스 (누수 가능 조건)
- 사용자 취향이 2D에서 **외딴·희소**해 진짜 이웃이 몇 개 없을 때 → 다음 순번에 아티팩트로 가까워진 무관 장르가 끼어들 수 있음.
- **군집 경계**에 걸친 소수 시청 사용자.
- 흔한 장르·조밀 카탈로그에선 가능성 낮지만 **0은 아님.**

## 제안 (분리) — 4.3/4.4 때 결정
추천 kNN을 **2D가 아니라 고차원 특징공간(코사인)** 에서 돌린다. build_coords가 이미 저장하는 모델/TF-IDF 벡터(`coords_model.pkl`)를 재사용.

| | 현재(결합) | 분리 후 |
|---|---|---|
| 추천 kNN | 2D 좌표(유클리드) | **고차원 TF-IDF(코사인)** |
| 지도 | 2D 좌표 | 2D 좌표(**표시 전용**) |
| 아티팩트 추천 누수 | 이론상 가능 | **차단** |

- 핵심: **"보는 것(2D 지도)"과 "고르는 것(고차원 추천)"을 분리.**
- 메트릭 일관성: 고차원은 코사인이 자연스럽다(TF-IDF). UMAP도 metric="cosine"이라 *국소* 순위는 비슷하게 나오겠지만, 전역 오염이 사라지는 게 이득.

## 트레이드오프 / 미해결
- 추천 시점에 **고차원 벡터를 로드**해야 함(현재 `_all_movies()` 2D 캐시처럼 1회 로드 캐시면 됨). 벡터 차원이 큼(희소) → 메모리·연산 약간 증가.
- 신규 영화는 `coords_model.pkl`로 `transform`해 고차원 벡터도 얻어야 함(좌표 적재 시 같이 캐시 가능).
- MMR·미탐색 KDE도 2D 기반(A-09) → 추천을 고차원으로 옮기면 **이들도 같이 정렬**할지 검토 필요(밴드·KDE는 2D 유지 가능, 거리 점수만 고차원).
- 친구 추천(A-10 max-kNN)도 같은 엔진이라 **함께 전환**해야 일관(`knn_to_set` 헬퍼를 고차원으로).

## 결정
- **지금은 보류.** 데모상 누수 0, 국소 밀도가 실효 방어. 지도 UX(겹침 분산·10점 표기 등)는 그대로 진행.
- **4.3(추천 페이지) / 4.4(지도 탐색 탭) 작업 시 재검토** — 그때 추천 품질을 직접 보며 분리 적용 여부 결정. 엣지 케이스(희소 취향)가 실제로 거슬리면 전환.
