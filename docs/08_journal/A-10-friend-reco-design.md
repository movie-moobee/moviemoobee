# A-10 · 친구 "같이 볼 영화" 추천 설계 (계획) — 5.3 / 5.4

- 날짜 / 일정ID / 담당: 2026-06-20 · 5.3·5.4 (협업 A+B) 선행 설계 · 김호준
- 상태: **계획/설계 (미구현)** — 5.4 구현 전 합의용. B 공유 필요(협업 항목).
- 한 줄 요약: 친구 같이 볼 영화 후보를 기획서의 **무게중심 "두 좌표 사이"가 아니라, 두 사람 본 영화 집합 kNN의 `max`**로 뽑는다(추천 kNN 전환과 일관). **LLM은 선택이 아니라 "대화 재요청 + 자연어 설명" 레이어.** user_coord는 일몰 후보.

## 배경 / 문제
- 기획서(와이어 13번·스케줄 5.4): **"같이 볼 영화 AI(챗봇) — 두 좌표 사이(겹침 영역) 후보를 채팅으로 추천, '더 가볍게' 후속 요청에 LLM이 다시 골라줌."**
- **"두 좌표 사이" = 두 사람의 무게중심 사이.** 무게중심은 다봉 취향에서 골짜기에 떨어짐(A-08 검증) → "골짜기↔골짜기 사이"는 더더욱 빈 구역 → LLM이 엉뚱한 후보를 받음. **LLM이 아니라 후보 영역 정의가 문제.**

## 결정 (설계)
1. **후보 산출(알고리즘 = A 몫)**: 둘 다 안 본 영화 `c`에 대해
   ```
   knn_A(c) = c에서 A의 좋아한(별점>3) 영화 3-NN 평균거리
   knn_B(c) = c에서 B의 좋아한 영화 3-NN 평균거리
   score(c) = max(knn_A(c), knn_B(c))        ← 둘 다 가까워야 점수 좋음
   후보 = score 최소 Top N
   ```
   안전 추천의 kNN 엔진을 그대로 재사용(`knn_to_set(후보, 본영화집합, k)` 헬퍼로 빼면 1인=1회, 친구=2회+`np.maximum`).
2. **대화·설명(LLM = 공통)**: 위 후보 풀을 받아 (a) **자유 재요청**("더 가볍게/공포 빼고/짧은 거") 대화로 좁히고, (b) **자연어 narration**("둘 다 액션 좋아하고 친구만 본 누아르 색을 더한…")으로 사회적 "왜"를 설명. **LLM은 '선택'이 핵심이 아님** — 단순 추천이면 LLM 없이 카드로도 가능. 소셜·대화 경험을 살릴 때만 LLM.

## 왜 `max` (mean/sum 아님) — "약한 고리"
같이 볼 땐 **한 명이라도 별로면 실패** → 가장 덜 만족하는 사람을 기준으로 최적화해야 함.
- `max` = 그 후보에서 **더 먼(덜 좋아하는) 사람의 거리** → 이걸 최소화 = 둘 다 어느 정도 만족 보장.
- `mean`/`sum`은 한 명의 극단적 만족(거리≈0)이 다른 한 명의 불만족을 가려 **한쪽 전용 영화**를 뽑음.

### 데모 실증 — 불균형 |kA−kB| (낮을수록 둘 다 균형)
| 친구 쌍 | **max** | mean |
|---|---|---|
| 공포 + 로맨스 | **1.87** | 3.93 |
| 액션 + 코미디 | **3.04** | 6.57 |
| demo_a + demo_b | **0.82** | 3.38 |

- **공포+로맨스**: mean=로맨스 판타지(kA 3.95/kB 0.02, B전용) ↔ **max=다크 판타지(빅 피쉬·해리 포터, kA 3.2/kB 1.3) 다리**.
- **액션+코미디**: mean=마블(kA 0.02/kB 6.59, A전용) ↔ max=가족 애니(kA 3.4/kB 6.4). 단 **max값 자체가 커서 "겹침 약함"을 정직하게 신호** → LLM이 절충안 설명하는 자리.
- **demo_a+demo_b**(실제 친구): mean=로코(B쪽) ↔ **max=스릴러/드라마(매치 포인트·위험한 정사, 불균형 0.82)** 거의 완벽 균형.
- 보너스: **다리 장르가 자연스럽게 떠오름**(공포+로맨스→다크 판타지, 액션+코미디→가족 애니, demo_a+b→스릴러/드라마).

## user_coord(무게중심) 함의
| 용도 | 무게중심 필요? |
|---|---|
| 안전·미탐 추천 | ❌ kNN으로 졸업(A-08/A-09) |
| **친구 후보** | ❌ **두 집합 kNN max로** (이 문서) |
| 지도 마커(3.3) | △ 선택(글로우 별로 충분, 마커 뺄 수도) |
- → 친구·지도가 둘 다 무게중심을 안 쓰게 되면 **user_coord 완전 제거 가능**. 그 전까지는 캐시·응답에 "데워둠"(제거는 3.3·친구 정리 후 일괄).

## 미정 / 후속 (5.4 구현 때 데이터로)
- 두 사람 **본 영화 수·취향 폭 차이** 보정(정규화·가중)이 필요한지.
- 후보 풀에서 **한쪽만 본 영화** 포함/제외(같이 *볼* 거라 둘 다 미관람이 기본).
- **겹침 약한 쌍**(max값 큼)의 UX — "두 분 취향이 꽤 달라요" 톤.
- LLM 프롬프트 설계(후보 메타·공통 시청작·narration 톤) + 비용/지연.
- 5.3 비교 지도의 **공통 시청작 ★**는 이미 집합기반이라 OK. 좌표 마커는 3.3과 같은 이슈.
