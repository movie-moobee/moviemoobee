# A-14 · 앵커(대륙) 지도 — 좌표 전면 재설계 (확정·구현 착수)

- 날짜 / 일정ID / 담당: 2026-06-23 · 4.x 좌표 재설계(A-11 연장) · 김호준
- 상태: **설계 확정, 구현 착수** — 좌표 레시피 검증 완료, build_coords 교체 진행
- 한 줄 요약: UMAP 2D는 "가까우면 비슷"이 안 통해(국소만 보존, 전역 거리 왜곡) 사용자가 지도를 오해한다. 추천 계산은 고차원에서, **지도는 앵커(장르 대륙) 기반으로 재설계**. 핵심 난제였던 collapse(같은 장르 영화가 한 점에 포개짐)를 **거시=장르 / 미시=키워드 스케일 분리**로 해결.

## 발단
- 사용자 계정으로 추천을 보다 "안전·미탐색이 다 같은 장르"·"취향요약 장르를 추천 안 함"을 발견(→ 별도 수정 [[A-13]] 미탐색 다양화·라벨 일치, daily-pick 고정, 카탈로그 prune).
- 더 근본 의문: 추천이 아쉬운 게 **2D UMAP 압축 손실** 때문 아닌가(제미나이 피드백 + [[A-11]]). 검증해보기로.

## 실험 여정 (전부 실측, 3,745편 prune 후 카탈로그)
1. **2D vs 고차원 안전추천(kNN)**: 고차원이 같은 장르 안 '질'이 확실히 나음(비포선라이즈→**비포선셋** 후속 정확히 집음, 로맨스의 SF누수 제거). 단 **단조로움(드라마/로맨스 독점)은 차원 무관** — 최대 군집에서 뽑히는 구조라 2D든 고차원이든 동일.
2. **고차원 클러스터별 안전**: 좋아한 영화를 고차원 KMeans로 2~3 봉우리로 나눠 봉우리마다 kNN → **단조로움 해소 + 후속편 정확도** 동시(판타지·스릴러·로맨스 다 살고 각 봉우리 안은 정확). ※ 이건 추천 트랙 개선안으로 **보류 기록**(아래 '관련 보너스').
3. **2D가 거짓말함을 증명**: 스릴러 5편(기생충·겟아웃·메멘토·셔터·위플래쉬) — 2D 내부거리 20.57 > 스릴러↔로맨스 14.86(거꾸로!), 고차원 0.575 < 0.891(정상). → 2D 좌표로 이웃 찾으면 기생충 옆에 노트북이 오는 일이 생김.
4. **앵커 지도 프로토타입**: 영화좌표 = 닮은 대륙들의 무게중심(softmax 가중). 대륙은 또렷해졌으나 **collapse**(같은 장르=같은 점, 고유좌표 52%)·다장르 끌림(기생충이 코미디로 쏠림).
5. **키워드 가중 스윕**: 키워드 비중↑ → collapse 해소(30→99%)·가오갤↔인셉션 분리(0.01→3.0). **그러나 대륙이 중앙으로 뭉침**(legibility 붕괴). → 전역 손잡이 하나로는 거시·미시 동시 충족 불가.
6. **하이브리드(채택)**: 거시=장르가중으로 대륙 배치 + 미시=키워드 SVD를 작은 오프셋으로 더함. α=0.5에서 **collapse 31→99%, 대륙퍼짐 8.0(또렷 유지), 인셉션·가디언즈가 SF 안에서 분리**. 양쪽 다 잡힘.

## 시도·결과 요약표
| 방식 | collapse(고유%) | 가오갤↔인셉션 | 대륙 legibility |
|---|---|---|---|
| 거시만(장르앵커) | 31% | 0.01 (포갬) | 또렷(퍼짐 7.9) |
| 키워드 가중만↑(장르1/키2.5) | 99% | 3.0 | **중앙 뭉침(붕괴)** |
| **하이브리드 α=0.5** | **99%** | ~2.8 (SF 안 분리) | **또렷(퍼짐 8.0)** |
| 하이브리드 α=1.0 | 99% | 6.25 (과분리, 가디언즈 구석) | 또렷 |

## 확정 좌표 레시피
```
거시(대륙 위치):
  X_macro = TFIDF(장르×3 + 키워드×1 + 감독×0.5), L2정규화
  앵커 = 주요장르(영화 ≥80편, ~16개)의 X_macro 중심벡터
  앵커 2D = MDS(앵커 코사인거리)  → ±10 스케일 (장르끼리 인접 배치)
  P_macro = Σ softmax(cos(영화, 앵커)/T) · 앵커2D     (T=0.1)

미시(대륙 내 분산):
  X_kw = TFIDF(키워드 only), L2정규화
  P_kw = TruncatedSVD(X_kw, 2D) → 표준화(평균0/분산1)

최종좌표 = P_macro + ALPHA · P_kw          (ALPHA=0.5, 튜닝 손잡이)
```
- **ALPHA는 상수로 분리** — 추후 0.5~0.7 조정 여지(↑면 분리 강해지나 과하면 대륙 이탈). 변경 시 재bake 필요.
- **결정론적·재fit 불필요**: 앵커·MDS·SVD·표준화 파라미터를 모델로 저장 → 신규 영화는 transform만. 기존 좌표 불변 = 전역 고정 불변식·친구 비교 안전(UMAP의 최대 약점 원천 제거).

## collapse 원인·해결 (핵심)
- 원인: 좌표가 "장르 앵커 K개와의 유사도"에만 의존 → 장르 프로필 같으면 같은 점.
- 해결: **거시(장르)·미시(키워드)를 다른 신호로 따로**. 키워드 가중치를 전역으로 올리면 대륙까지 뭉개지므로, 키워드는 *대륙 내 오프셋*으로만 작게 주입.
