# 무비무비 개발 일정 (2인 · 3주 · 15영업일)
> 아래 **무비무비_일정표_노션.csv** 를 노션에 가져오면 표/보드/타임라인/캘린더로 같이 작업할 수 있어요.
## 📥 노션에 가져오는 법
1. 노션에서 빈 페이지 → **`/csv`** 또는 **Import → CSV** 선택
2. `무비무비_일정표_노션.csv` 업로드 → **데이터베이스(표)** 로 생성됨
3. 속성 타입 변경 (가져온 직후엔 대부분 텍스트라 한 번 바꿔주세요):
   - **상태 → Status** (할 일 / 진행중 / 완료 / 보류)
   - **완료 → Checkbox** (CSV의 `Yes`는 체크됨, `No`는 해제로 들어옵니다)
   - **진행률 → Number** (표시 옵션에서 막대·링으로 보기 가능)
   - **담당 / 단계 → Select**,  **시작일·종료일 → Date**
4. 뷰 추가: **Timeline**(시작일=시작, 종료일=종료 → 간트처럼) / **Board**(상태 또는 담당 기준 칸반) / **Calendar**
5. **담당을 Person 속성**으로 바꾸면 실제 팀원을 멘션·할당할 수 있어요.
6. **리뷰 남기기**: 리뷰/메모 칸에 적거나, 각 작업 행을 열면 페이지가 되니 그 안에서 **댓글(@멘션)·체크리스트**로 길게 토론하세요.
